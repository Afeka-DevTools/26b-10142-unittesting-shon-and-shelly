### 📝 תיאור הפרויקט
פרויקט זה מכיל סדרת מתודות חישוביות ולוגיות מתקדמות בשפת Java (כמו בדיקת פלינדרומים, סדרת פיבונאצ'י, מציאת תדירות תווים וממוצעים). הפרויקט מלווה במערך מקיף של בדיקות יחידה אוטומטיות (Unit Tests) המבטיחות את תקינות הקוד ומונעות באגים בכל שינוי עתידי.

## 🛠 מדריך מפורט למשתמש המתחיל (צעד אחר צעד)

אם מעולם לא הרצת קוד או בדיקות תוכנה, המדריך הזה מיועד בדיוק עבורך. עקוב אחר השלבים הבאים כדי להפעיל את הבדיקות ולראות שהכל עובד בצורה תקינה:

### 1️⃣ שלב 1: פתיחת הפרויקט בסביבת העבודה
1. פתחו את תוכנת **Visual Studio Code (VS Code)**.
2. לחצו בתפריט העליון על `File` ואז על `Open Folder...`.
3. בחרו את תיקיית השורש של הפרויקט (התיקייה שבה נמצאים קובצי הקוד שלכם).

### 2️⃣ שלב 2: ניווט לחלונית הבדיקות המובנית (הדרך הקלה)
1. בסרגל הכלים הקיצוני ביותר בצד (לרוב בצד שמאל, או ימין אם הממשק בעברית), חפשו סמל שנראה כמו **מבחנה של מעבדה (Testing)** ולחצו עליו.
2. לאחר הלחיצה, תיפתח חלונית שתציג לכם רשימה מסודרת של כל פונקציות הבדיקה הקיימות בפרויקט (תחת המחלקה `AppTest`).

### 3️⃣ שלב 3: הרצת הבדיקות החזותיות
* **הרצת הכל:** בחלק העליון של חלונית המבחנה, לחצו על כפתור ה-**Play** הגדול (**Run Tests**) כדי להריץ את כל הבדיקות בבת אחת.
* **הרצת בדיקה בודדת:** אם ברצונכם לבדוק פונקציה ספציפית (לדוגמה, רק את הבדיקה של הפיבונאצ'י), תוכלו לעמוד מעליה ברשימה וללחוץ על כפתור ה-**Play הקטן** שמופיע לצדה.

### 4️⃣ שלב 4: הרצה חלופית דרך הטרמינל (שורת הפקודה)
אם אתם מעדיפים להריץ את הבדיקות דרך פקודה טקסטואלית:
1. פתחו את הטרמינל בתוך VS Code (על ידי לחיצה על מקשי הקיצור `Ctrl + \`` או דרך התפריט העליון: `Terminal -> New Terminal`).
2. העתיקו והדביקו את הפקודה הבאה ולחצו על **Enter**:
